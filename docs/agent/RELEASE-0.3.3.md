# MegaRustDesk 0.3.3 preview

Правую панель можно свернуть стрелкой; удалённому экрану возвращается 218px.
По умолчанию управление у человека. Одна кнопка «Передать Codex» / «Вернуть управление»
заменяет прежние пять кнопок. В свёрнутой панели остаётся быстрый возврат контроля.
Убраны пояснения про задачи и горизонтальная прокрутка панели.

Ручная вставка текста: кнопка «Вставить текст» или Ctrl+V над удалённым экраном.
Читается только текст и только при ручном управлении подключённым ПК с разрешённой
клавиатурой. Передача Codex, пауза и разрыв отменяют ожидающую вставку.
В MCP clipboard-метод не добавляется; автоматическая синхронизация, файлы и картинки
по буферу отключены. Сетевой протокол/relay не менялись.

Нативная Sciter-панель: 6/6 (1280×800, 900×600, 850×500, светлая/тёмная тема),
переключение контроля, сворачивание/возврат, reclaim и disabled/error states.
Браузерная fixture тех же markup/TIS: 6/6, без горизонтального переполнения и JS ошибок;
Sciter layout для неё переведён в flex, это не полноценный браузерный запуск native viewer.
Gate/ручная вставка: 17 тестов. Реальные protobuf сообщения: Unicode, все 256 сочетаний
левых/правых модификаторов и нейтральные отпускания Legacy/Map/Translate проверены локально.
При передаче контроля отпускаются все удержанные клавиши, а не только модификаторы.
Release build прошёл за 7m05s; portable self-test прошёл в двух путях, включая кириллицу,
без developer PATH. Проверены 13 MCP tools, binding и запрет автоматической смены цели.
Это preview: полная проверка на чистой Windows и физическая ручная вставка на второй ПК
ещё не подтверждены. Работающее соединение не перезапускается автоматически.
