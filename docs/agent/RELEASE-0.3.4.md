# MegaRustDesk 0.3.4 — исправление updater Windows job

Updater проверяет выход из собственного контейнера приложения по точному process
HANDLE. Наличие внешнего Windows job больше не считается ошибкой. Внешние ограничения
Windows сохраняются. Подписи, inventory, ожидание родителя, журнал и откат не отключены.

Нативный regression воспроизвёл прежний ложный отказ: helper уже переживает выход
приложения, но остаётся во внешнем job. Новый guard разрешает helper и по-прежнему
отклоняет обычный дочерний процесс, который погибает с приложением.

Если 0.3.2/0.3.3 уже показывает «Updater остался внутри Windows job», скачайте маленький
repair-update.cmd из этого релиза и запустите на том ПК при открытом MegaRustDesk.
Он найдёт папку, сам скачает обновление и проверит подпись доверенным старым EXE.
По запросу полностью закройте программу и нажмите Enter в восстановителе.
Архив вручную распаковывать не нужно; data сохраняется. Чужие процессы не завершаются.
После однократного восстановления следующие обновления устанавливаются обычной кнопкой.

Исходники/подписи/результаты проверок доступны в релизе; полная clean-Windows и проверка
на физическом втором ПК остаются отдельными воротами приёмки.
